From ideas to working web pages

You do not need previous programming experience. Start with familiar services, learn a web concept, practise it, and connect it to your programme.

Explore web terminology, browsers, URLs and how a visitor retrieves a page.

Create

STEP 03

Apply

Build a library service website or a records-centre information website.
