# Web Design — IIA Undergraduate Course

**Programmes:** Bachelor of Library and Information Studies (BLIS) and Bachelor of Records Management Systems (BRMS).

This self-paced learning website introduces the web, design principles, HTML, CSS, introductory JavaScript and practical applications for libraries, archives and records services. Both programmes follow the same core lessons, with examples relevant to their professional work.

## Begin studying

Open the [course homepage](index.html), then select a unit. Each unit includes detailed notes, an embedded PDF lecture presentation, a guided practical exercise, a short assignment and a scored self-check quiz. Quizzes draw eight questions from a larger bank, shuffle the questions and answers, and explain missed responses after submission.

## Course units

1. Introduction to the Web
2. Principles of Good Web Design
3. Introduction to HTML
4. Organising Web Content
5. HTML Tables
6. HTML Forms
7. Introduction to CSS
8. Page Layout and Responsive Design
9. Usability and Website Evaluation
10. Introduction to JavaScript
11. Web Technologies in Information Institutions
12. Website Hosting and Publishing

## Practicals and assignments

- [Practicals](practicals/index.html) — guided exercises and starter examples
- [Assignments](assignments/index.html) — small tasks corresponding to each unit
- [Resources](resources/index.html) — PDF presentations, worksheets and exercise files

Use **fictional information** in examples and assignments. Do not upload passwords, confidential records, personal borrower details or restricted documents.

Formal submission dates and the Google Form submission link will be communicated separately. Scores from self-check quizzes are for practice and are not official submissions.
