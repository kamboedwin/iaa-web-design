Unit 5 — HTML Tables

Practical worksheet | Library and Information Studies / Records Management Systems

Choose a fictional library catalogue or records inventory. Create one table with a caption, four columns and at least three data entries. Use only made-up data.

1. Your chosen topic and table caption

2. Four column headings

3. Example HTML structure

<table>
  <caption>Your table caption</caption>
  <thead>
    <tr>
      <th scope="col">Column 1</th>
      <th scope="col">Column 2</th>
      <th scope="col">Column 3</th>
      <th scope="col">Column 4</th>
    </tr>
  </thead>
  <tbody>
    <!-- Add rows here -->
  </tbody>
</table>

4. Check your finished table

□ Caption identifies the table
□ Column headings use <th>
□ Three fictional entries are complete
□ Cells appear under correct headings
□ No real confidential information is included
