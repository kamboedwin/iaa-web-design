Unit 8 — Responsive Layout Practical

Learn how a service page changes when its available width changes.

Part A. Explore the webpage

  1. Open the library or records-centre starter webpage.
  2. Make the browser narrow and then wide. Observe how the service cards change.
  3. In styles.css, find the .services rules and the media query.
  4. Change the gap from 16px to 24px. Save and refresh.
  5. Choose a breakpoint that keeps the card text readable.

Part B. Explain what happened

1. Why do the cards stack on narrow screens?

2. Which CSS rule changes the arrangement on wider screens?

3. What would happen if a card had a fixed width of 900px?

Part C. Check your page

My page has a readable heading, usable links, consistent gaps, and no unnecessary page-wide horizontal scrolling.
